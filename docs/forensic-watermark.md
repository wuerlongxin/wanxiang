# 卡牌取证水印

印刷卡牌正面和背面在完成全部绘制后，会嵌入一枚不可见的确定性指纹。指纹由套牌 ID、版本族、版本号、P2P CID、卡牌 ID 与正反面标识共同生成，因此同一版本的同一面可复核，不同版本、卡牌或面会得到不同指纹。

实现使用分散的相邻像素通道奇偶编码：每个采样最多改变一个 RGB 通道 1/255，并以九个独立位置重复同一位后多数表决。它不改变 Alpha、画布尺寸、版式或现有可见所有权标记。

## 能力边界

- 可验证：原始画布像素、PNG 及其他保持像素和尺寸不变的无损副本。
- 有一定冗余：少量孤立像素最低位变化可由重复投票吸收。
- 不保证：JPEG/HEIC 等有损重压缩、缩放、旋转、裁切、截图、色彩空间往返或主动清洗最低位。PDF/X-4 的 CMYK/JPEG 印刷成品仍以可见所有权标记、CID 与签名来源信息作为主要追溯手段。
- 该指纹用于候选作品的取证核验，不是秘密签名，也不单独证明著作权。P2P 来源真实性仍由 Ed25519 签名验证。
